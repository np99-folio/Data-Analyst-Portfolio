Power Query Automation & Transformation Project

-- Power Query (Excel & Power BI): Built a full end‑to‑end workflow using the Excel Power Query Editor to import, clean, transform, and export data efficiently.

-- Automated Data Cleaning: Used trimming, null‑handling, replacing, splitting, date conversion, and conditional logic to cleanse raw datasets and ensure high data quality.

-- Live Refresh Automation: Configured queries to refresh automatically on open or on demand, enabling regularly updated datasets without manual effort.
